### 2. [proj_graf_02 - Wczytywanie obrazów PPM (P3/P6)](./proj_graf02/README.md)

### 3. [proj_graf_03 - Konwersja przestrzeni barw (RGB ↔ CMYK) + kostka RGB](./proj_graf03/README.md)

### 4. [proj_graf_03 - Przekształcenia punktowe + filtry poprawy jakości](./proj_graf03/README.md)

### 5. [proj_graf_05 - Histogram + binaryzacja](./proj_graf05/README.md)

### 6. [proj_graf_06 - Krzywa Béziera](./proj_graf06/README.md)

### 7. [proj_graf_07 - Figury (wielokąty) + transformacje + serializacja](./proj_graf07/README.md)

### 8. [proj_graf_08 - Filtry morfologiczne (dylatacja, erozja, otwarcie, domknięcie, hit-or-miss)](./proj_graf08/README.md)

### 9. [proj_graf_09 - Obliczanie procentu terenów zielonych (parametryzacja koloru)](./proj_graf09/README.md)
