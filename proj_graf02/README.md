Funkcjonalności:
- Wczytywanie i wyświetlanie obrazów: **PPM P3**, **PPM P6**, **JPEG**
- Wydajne wczytywanie PPM (np. blokowo dla P6)
- Zapis do **JPEG** z wyborem jakości/kompresji
- Podgląd obrazu:
  - zoom in/out
  - przesuwanie (pan) przy powiększeniu
  - (opcjonalnie) podgląd wartości **RGB** pikseli przy dużym zoomie
- Skalowanie liniowe kolorów (rozciąganie zakresu kanałów)
- Obsługa błędów: komunikaty dla złych plików/formatów/uszkodzonych nagłówków

Skróty:
- `Ctrl +` / `Ctrl -` – zoom
- `Mouse drag` – przesuwanie przy powiększeniu
- (opcjonalnie) `H` – podgląd wartości pikseli
