Funkcjonalności:
- Rysowanie krzywej Béziera dowolnego stopnia
- Definiowanie punktów kontrolnych:
  - myszą (klik / dodaj punkt)
  - polami tekstowymi (lista punktów / pojedynczy punkt)
- Edycja:
  - przeciąganie punktów (drag&drop)
  - podmiana wartości w polach tekstowych po zaznaczeniu punktu
- Przeliczanie krzywej w czasie rzeczywistym (realtime)

Skróty:
- `Del/Backspace` – usuń zaznaczony punkt
- `Esc` – anuluj bieżącą akcję / odznacz
