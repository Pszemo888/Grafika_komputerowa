Funkcjonalności:
- Wczytanie obrazu i binarizacja (próg ustawiany suwakiem/polem)
- Operacje morfologiczne:
  - dylatacja
  - erozja
  - otwarcie
  - domknięcie
  - hit-or-miss
- Definiowanie elementu strukturyzującego (SE):
  - dowolny rozmiar (np. 1–51)
  - edycja wartości w siatce (np. -1 / 0 / 1)
- Tryb pracy:
  - wynik jako wejście (łańcuchowanie operacji)
  - reset wyniku (powrót do obrazu po progu)
- Podgląd:
  - oryginał obok wyniku/binarki (porównanie)

Skróty:
- `R` – reset wyniku (opcjonalnie)
- `Esc` – anuluj/odznacz (opcjonalnie)
